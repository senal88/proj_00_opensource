Pipeline operacional


Quatro blocos independentes. Copie cada um e aplique no seu repositório local.







1 · channels.txt (exemplo mínimo)


Três canais do catálogo, no formato <domínio> <url>/videos.


# Formato:  
self_hosted https://www.youtube.com/@andre_lug/videos
self_hosted https://www.youtube.com/@novaonda2025/videos
reversa https://www.youtube.com/@LiveOverflow/videos







2 · check_channels.sh


Script completo, sem alterações.


#!/usr/bin/env bash
set -euo pipefail

CHANNELS_FILE="${1:-channels.txt}"
URLS_FILE="${2:-urls.txt}"
LIMIT=3

if [[ ! -f "$CHANNELS_FILE" ]]; then
  echo "Erro: arquivo '${CHANNELS_FILE}' não encontrado." >&2
  exit 1
fi

touch "$URLS_FILE"
NOVOS=0

while read -r domain channel_url; do
  [[ -z "${domain:-}" || "$domain" == \#* ]] && continue

  video_ids="$(yt-dlp --flat-playlist --playlist-end "$LIMIT" \
    --print "%(id)s" --no-warnings "$channel_url" 2>/dev/null || true)"

  if [[ -z "$video_ids" ]]; then
    echo "[AVISO] Nenhum vídeo obtido de: ${channel_url}" >&2
    continue
  fi

  while IFS= read -r vid; do
    [[ -z "$vid" ]] && continue
    if ! grep -Fq "$vid" "$URLS_FILE"; then
      echo "${domain} https://www.youtube.com/watch?v=${vid}" >> "$URLS_FILE"
      echo "[NOVO] ${domain} -> https://www.youtube.com/watch?v=${vid}"
      NOVOS=$((NOVOS + 1))
    fi
  done <<< "$video_ids"

done < "$CHANNELS_FILE"

echo "Concluído. Novos vídeos adicionados em ${URLS_FILE}: ${NOVOS}"

Notas técnicas


    

  • Depende de yt-dlp instalado e disponível no PATH.
    • 

  • --flat-playlist --playlist-end 3 lista os IDs dos últimos vídeos e não baixa mídia.
    • 

  • A deduplicação é feita por ID dentro de urls.txt.
    • 

  • Atenção: grep -Fq "$vid" casa substring em qualquer parte do arquivo. Em produção, prefira casar o campo exato, por exemplo grep -Fq "watch?v=${vid}".
